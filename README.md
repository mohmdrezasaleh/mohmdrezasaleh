## 🧑‍💻 About me
 
I'm a Junior DevOps Engineer with a technical support background and hands-on experience in **Linux web hosting environments**. Day to day I work with control panels, web servers and troubleshooting, and I'm building my way into automation, containers and cloud-native tooling.
 
I believe in **learning in public**: everything I learn, I document and take notes on, so every setup, mistake and fix ends up as a written record I (and hopefully others) can reuse.
 
- 🔧 Working with **Linux, Bash, Python, Docker and GitLab CI/CD**
- ☸️ Exploring **Ansible, Terraform, Kubernetes (k3s), Helm and ArgoCD**
- 📊 Setting up **monitoring and logging** with Prometheus, Grafana and Loki/ELK
- 📝 Documenting my learning journey, one note at a time
- 📍 Based in Qom, Iran
